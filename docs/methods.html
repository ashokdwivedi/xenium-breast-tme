Methods

Methods, reproducibility and limitations

Every parameter, every threshold, and an honest account of what this analysis cannot tell you.

Data

Two public datasets, both downloaded by scripts/download_data.sh, which also writes a SHA256SUMS manifest so a rerun can be verified byte-for-byte.

  • 10x Genomics Xenium In Situ, FFPE Human Breast Cancer, Replicates 1 and 2. A 313-gene breast panel on two serial sections of one tumour block; 286,532 segmented cells in total. Described in Janesick et al., Nature Communications 2023.
  • Breast-cancer scRNA-seq atlas of Wu et al., Nature Genetics 2021 (GEO accession GSE176078), used as the label-transfer reference.

Pipeline

bash scripts/download_data.sh     # public data + checksums
make qc                           # stage 1 -> results/tables/qc_scorecard.csv
make annotate                     # stage 2 -> data/processed/Rep1_annotated.h5ad
make spatial                      # stage 3 -> results/tables/immune_distance_stats.csv
python scripts/04_build_site.py   # this website
make test                         # unit tests, no data required

Stage 1 — quality control

Counts, genes, control-feature fraction, cell and nucleus area and transcript density are computed per cell from the raw matrix with negative-control features retained (they are dropped only after the control rate has been computed from them). Run-level rates are recomputed from the matrix rather than copied from the vendor metrics_summary.csv, which is carried alongside for comparison. Regional artefacts are tested by binning the section into 100 µm squares and computing Moran's I with a queen-contiguity weight matrix and a 199-permutation null.

Stage 2 — cell typing

Counts are normalised to a fixed total per cell and log1p-transformed; the full panel is used as features, since variable-gene selection is meaningless on a targeted panel where every gene was chosen for informativeness. PCA to 30 components, Leiden clustering over a resolution sweep with the chosen value recorded in the config, and Harmony integration of Xenium with the reference before a distance-weighted k-nearest-neighbour vote. Cells below the confidence floor are left unassigned. Marker scoring uses scanpy.tl.score_genes against curated per-lineage sets, aggregated to clusters.

Stage 3 — spatial analysis

Delaunay graph with a distance cap; neighbourhood enrichment by label permutation with positions held fixed; niches by k-means on fixed-k neighbourhood composition vectors; interface enrichment by permutation with Benjamini–Hochberg correction across populations. Distances are Euclidean in microns on the vendor's cell centroids.

Reproducibility

  • Pinned environment. environment.yml for conda; pyproject.toml for pip.
  • Deterministic. One seed in the config threads through Leiden, Harmony, k-means and every permutation test.
  • Tested. 21 unit tests on synthetic fixtures with known answers, run in CI on every push. The fixtures include a section with two spatially separated compartments, so niche recovery and the interface null can be checked against a ground truth.
  • Checksummed inputs. The download script writes SHA-256 sums for every file it fetches.
  • No hand-edited numbers. Every figure is produced by a script, and every number on this website is injected from results/tables/ when the site is built.

What this analysis cannot tell you

  • One tumour. Two sections of one block. Nothing here generalises to breast cancer as a disease; the value is in the method, not the biological claim.
  • No morphology channel. H&E-to-DAPI registration, and therefore any pathologist-annotated region analysis, is outside what this public bundle supports.
  • Segmentation is nucleus expansion. Transcript misassignment between tightly apposed cells is unquantified here and is worst exactly at the tumour boundary.
  • Lineage, not state. The panel cannot support exhaustion, activation or EMT calls, so none are made.
  • Proximity is not interaction. Every spatial result is a description of arrangement.
  • Assumption diagnostics were not run. The permutation tests are distribution-free by construction; no further residual or normality checks were performed.
